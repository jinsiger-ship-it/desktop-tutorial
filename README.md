# FANPLAY — desktop-tutorial 실행본

[**⚾ 게임 바로 실행 (GitHub Pages)**](https://jinsiger-ship-it.github.io/desktop-tutorial/#game) · [**사이트 홈**](https://jinsiger-ship-it.github.io/desktop-tutorial/#home)

> **실행 조건:** 위 링크는 GitHub Pages 배포가 성공하고 저장소 설정에서 Pages가 활성화된 경우에만 열립니다. 현재 이 저장소는 **비공개(private)**이므로 계정/요금제와 Pages 설정에 따라 사용자가 직접 배포를 활성화해야 할 수 있습니다. 링크는 실행 *예정 주소*이며, 실제 접속 성공 여부는 별도 확인이 필요합니다.

## 프로젝트 개요

[원본 LLM-VIPS](https://github.com/jinsiger-ship-it/LLM-VIPS) `main`의 파일을 이 저장소로 복사하여 독립적으로 실습·실행할 수 있게 구성했습니다. 야구 티켓 제작·수집, 커뮤니티 시연, 선수 커리어 게임이 포함됩니다. 원본 저장소는 변경하지 않았습니다.

### 이번 게임 수정사항 (2026-11-17)

- 신인 유망주 3명 중 선택 → **선수 이름을 직접 입력하고 포지션(타자/투수) 선택**
- 타자: **우타 / 좌타**, 투수: **우투 / 좌투**
- 타자 능력치: **컨택 / 파워 / 주루 / 선구안 / 수비 / 송구**
- 투수 능력치: **구속 / 구위 / 제구 / 변화구 / 체력 / 멘탈**
- 각 능력치 정수 **0~100점**, 시작 총합 **300점**(평균 50점); 직접 재분배
- 기존 자동 시즌 진행·게임 기록과 연결하고, 이전 저장 형식(`rules:2/3`)의 읽기 로직 유지
- 새 선수는 `rules:4`로 기록되며 기본 시뮬레이터의 3개 내부 능력치로 환산해 사용
- 이번 버전은 **선수 생성 화면 개편**입니다. 6개 능력치 각각이 경기 결과에 독립적인 영향을 주도록 완전히 재설계한 것은 아닙니다.

### 실행 방법

**웹에서 실행:** GitHub 저장소 → **Settings → Pages → Build and deployment → Source: GitHub Actions**로 설정. `main`에 커밋된 배포 워크플로가 성공하면 위 **게임 바로 실행** 링크를 누릅니다.

**로컬에서 실행:** 저장소 전체를 받아 `index.html`을 브라우저로 열거나 로컬 웹서버에서 제공합니다. 예: `python -m http.server 8000` 실행 후 [http://localhost:8000/#game](http://localhost:8000/#game) 접속. 브라우저 비회원 데이터는 해당 브라우저에 저장됩니다.

**로컬 계정/SQLite 실행:** Node.js 24 이상에서 `node server.cjs` 실행 후 [http://127.0.0.1:8080/#game](http://127.0.0.1:8080/#game) 접속. GitHub Pages에서는 서버 기반 로그인 기능이 제공되지 않습니다.

### 검증 및 제한

- JavaScript 문법 검사는 배포 워크플로에 포함했습니다.
- 수정 선수 생성의 능력치 검사·1시즌 진행·구버전 복원은 별도 기본 로직 테스트를 수행했습니다.
- **실제 배포/브라우저 통합 테스트는 아직 미확인**이며, 결과가 확인되면 README에 추가해야 합니다.
- 웹 실행 링크는 GitHub Pages 설정에 따라 열리지 않을 수 있습니다.
